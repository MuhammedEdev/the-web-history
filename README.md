# 🌐 THE WEB HISTORY // İnternet Zaman Makinesi (1990 - 2026)

1990'ların analog şafağından 2026'nın uzamsal internet çağına uzanan 36 yıllık teknolojik devrimi keşfedin. Bu proje, dönemlerin ruhunu yansıtan interaktif bir kullanıcı deneyimi sunar.

---

## ✨ Öne Çıkan Özellikler // Key Features

| Özellik | Açıklama / Description |
| :--- | :--- |
| **Era-Morphing UI** | Slider kaydırıldığında 90'lar (Retro), 2000'ler (Modern) ve Gelecek (Cyber) tasarımları arasında anlık görsel dönüşüm. |
| **Zero-Image Build** | Hiçbir harici görsel (.jpg, .png) kullanılmadı. Tüm atmosfer saf CSS yetenekleriyle (Glassmorphism, Retro UI, Cyberpunk) oluşturuldu. |
| **Bento Grid** | Modern ve şık bir ızgara düzeni ile optimize edilmiş veri sunumu. |
| **Multi-Language** | Tam kapsamlı Türkçe ve İngilizce dil desteği (TR/EN). |
| **Custom Cursor** | İnteraktif, `mix-blend-mode` özellikli dinamik imleç takibi. |

---

## 🛠️ Kullanılan Teknolojiler // Tech Stack

- **HTML5:** Semantik yapı ve Bento Grid iskeleti.
- **CSS3:** Custom Variables, Backdrop-filter, Animasyonlar ve Dönemsel Era sınıfları.
- **Vanilla JavaScript:** Veri tabanlı (Data-driven) içerik motoru ve slider mantığı.
